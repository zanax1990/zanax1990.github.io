# Personal Website

Source files for [zanax1990.github.io](https://zanax1990.github.io/), a concise academic and technical profile built with GitHub Pages and the Jekyll Minimal theme.

The site includes a research summary, selected projects, publication information, a curriculum vitae, and links to GitHub and Google Scholar.

## Files

- `index.md` — page content and local styling
- `_config.yml` — GitHub Pages configuration
- `profile.jpg` — profile image
- `Jahan_CV.pdf` — downloadable curriculum vitae
